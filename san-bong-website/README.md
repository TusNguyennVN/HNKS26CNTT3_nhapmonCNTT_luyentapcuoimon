# GreenField – Đặt sân bóng mini.
Website đặt sân bóng mini, trong đó chữ đặt sân in đậm và chữ bóng đá mini in nghiêng.
## Thư mục
| Thư mục | Nội dung |
| --- | --- |
| docs | Tài liệu bàn giao |
| data | Bảng tính đặt sân |
| logs | Log truy câp website |
